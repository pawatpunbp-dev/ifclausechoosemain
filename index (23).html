🔗 If Clause Quiz

เลือก “ผล” ที่สมเหตุสมผลกับ “เหตุ” · If + Present, will + V1 · ม.3

วิธีเล่น
  1. มี 20 ข้อ ข้อละ 1 คะแนน (เต็ม 20) ทำทีละข้อ
  2. แต่ละข้อมีประโยคส่วน If และตัวเลือก 4 ข้อ (A–D) ให้เลือกผลที่เกิดขึ้นที่สมเหตุสมผลที่สุด
  3. กดวงกลม A B C D เพื่อเลือก แล้วกด “ยืนยันคำตอบ” (ยืนยันแล้วแก้ไม่ได้)
  4. แตะคำภาษาอังกฤษคำไหนก็ได้ จะเห็นคำอ่านและคำแปลไทยที่แถบด้านล่าง ไม่เสียคะแนน
  5. ตอบข้อไหนแล้ว นับคะแนนจากการตอบครั้งแรกเท่านั้น แก้ไม่ได้ กดปุ่ม 🏠 Home ออกไปแล้วกลับมาทำต่อได้ ข้อที่ทำแล้วไม่หาย
  6. จบ 20 ข้อแล้วจะได้ Score Report ให้ถ่ายภาพหน้าจอส่งครู (หลังจบ ฝึกซ้ำได้ แต่ไม่นับคะแนน)

กรุณากรอกชื่อ เลขที่ และห้องให้ครบก่อนเริ่มเล่น

🧪 โหมดฝึก: ไม่นับคะแนน
เลือกวงกลม A–D แล้วกดยืนยัน · แตะ คำ เพื่อดูคำอ่าน/คำแปล
